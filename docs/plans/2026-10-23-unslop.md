# unslop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code plugin that runs the four-stage reference → directions → iterations → final design process in any project.

**Architecture:** One orchestrator skill (`skills/unslop/SKILL.md`) with one reference file per stage, prompt/brief templates, two static HTML viewers (reference gallery, prototype switcher) that read generated `*.js` data files so they work over `file://` and `localhost`, and small Python stdlib scripts for dependency checks, scaffolding the `design/` tree and building the switcher manifest.

**Tech Stack:** Markdown skills; Python 3.9+ stdlib (scripts, `unittest`); plain HTML/CSS/JS (no build); `claude plugin validate`.

**Spec:** `docs/specs/2026-10-23-unslop-design.md`

## Global Constraints

- Python scripts: stdlib only, run on Python 3.9 (`python3 -I`).
- Viewers: no external scripts; fonts optional; light and dark; keyboard reachable; work over `file://`.
- Output only under `<project>/design/`; never write project-root DESIGN.md/PRODUCT.md.
- Stage counts default 5 styles / 2 skills / 3 iterations; app-screen briefs use impeccable only.
- Never generate or source imagery; reserve slots with flat CSS stand-ins.
- impeccable install: `npx impeccable install` (Node ≥ 18.19). tasteskill install: `npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"` or `/plugin marketplace add Leonxlnx/taste-skill` + `/plugin install taste-skill@taste-skill`.

## Review Focus

- Project already has a `design/` folder → scaffold must not overwrite existing files (test in Task 2).
- Build folder without `meta.json` → manifest still lists it using the folder name (Task 2).
- Gallery with zero or one group, or an image that fails to load → viewer renders, no JS error (Task 3).
- Port 8000 in use → serve script picks the next free port (Task 2).
- Skill installed globally or as a plugin rather than in the project → dependency check finds it (Task 2).

### Task 2: Scripts

**Files:** `skills/unslop/scripts/{check_deps.py, scaffold.py, manifest.py, serve.py}`, `tests/test_scripts.py`.

**Interfaces (Produces):**
- `check_deps.py [--project DIR] [--json]` → prints per dependency `{name, found:bool, where:str|None, version:str|None}` for `impeccable`, `design-taste-frontend`, `node`, `python3`, `chrome`. Skill search order: `DIR/.claude/skills/<n>`, `~/.claude/skills/<n>`, `~/.claude/plugins/cache/**/skills/<n>`. Version from SKILL.md frontmatter `version:` when present.
- `scaffold.py DIR` → creates `DIR/design/{references, stage-2, stage-3, final}`, copies `templates/brief.md`, `templates/decisions.md`, `assets/index.html`, `assets/gallery.html` (to `references/`) only if absent; prints created/kept paths.
- `manifest.py DIR` → scans `DIR/design/stage-2/*/`, `stage-3/*/`, `final/` for `index.html`; reads optional `meta.json {title, direction, skill, thesis}`; writes `DIR/design/manifest.js` as `window.DS_MANIFEST = {stages:[{key, label, builds:[{path, title, direction, skill, thesis}]}]};`.
- `serve.py DIR [--port 8000]` → serves `DIR/design` on the first free port ≥ given; prints URL.

- [ ] Tests (unittest, temp dirs): `test_scaffold_creates_tree`, `test_scaffold_keeps_existing_files`, `test_manifest_reads_meta`, `test_manifest_without_meta_uses_folder_name`, `test_manifest_sorted_by_folder`, `test_find_skill_in_project_then_home`, `test_free_port_skips_busy`.
- [ ] Run `python3 -m unittest discover tests` → FAIL, implement, → PASS.
- [ ] Commit.

### Task 3: Viewers

**Files:** `skills/unslop/assets/gallery.html`, `skills/unslop/assets/index.html`, `tests/fixtures/` (sample data + tiny images).

- gallery.html loads `gallery-data.js` (`window.DS_GALLERY = {title, groups:[{id, name, feel, vocabulary:[str], images:[{file, source, note}]}]}`), shows groups by design style (no feature tags), click-to-enlarge lightbox (Esc closes, arrows navigate), checkbox per group, counter "n of N picked" (N = `DS_GALLERY.pick || 5`), "Copy my picks" → clipboard text `Picks: <name>, <name>…` with fallback textarea.
- index.html loads `manifest.js`; tabs for stage → build; iframe preview; "open in new tab"; build thesis shown; links to references gallery; empty state when no builds.
- [ ] Verify with Playwright against fixtures served by `serve.py`: groups render, lightbox opens/closes, copy text correct, missing image shows placeholder, switcher tabs swap iframe src, zero-build empty state; no console errors.
- [ ] Commit.
